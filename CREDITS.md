# Credits

## Original project

LoopsubD 2 is based on the original **Loop Subdivision** plugin for SketchUp created by:

**Nathan B (NB70)**

The original source identifies Nathan B as the author and dates the source to June 2009. The original project was distributed through Guitar-List and later appeared in the NB70 GitHub repository.

## LoopsubD 2

**Development:** Marcos Netto

LoopsubD 2 is a substantial evolution of the original plugin, including the Control Cage workflow, separate generated surface, subdivision levels, Crease support, visual Crease marking, automatic updates, material handling and SketchUp 2020 compatibility improvements.

## Development assistance

**OpenAI ChatGPT**

Used as a development assistant during the evolution of LoopsubD 2 for source-code analysis, architecture discussions, debugging, Ruby/SketchUp compatibility work, testing strategies and documentation.

The original authorship of the NB70 plugin remains attributed to Nathan B. LoopsubD 2 development is attributed separately to Marcos Netto.

## Technical reference

Loop subdivision is based on the subdivision-surface algorithm developed by **Charles Loop**.

The original project also references:

**Hugues Hoppe et al.** — *Piecewise Smooth Surface Reconstruction*  
https://hhoppe.com/psrecon.pdf

## Licensing history note

The original 2009 `loop_subdiv.rb` source examined during development does not contain a formal license declaration.

A later version of the source committed to the NB70 GitHub repository in 2012 contains the source-code comment:

`# Apache 2.0 license`

The available repository history does not establish when or under what circumstances this notice was introduced. The project therefore records this history explicitly instead of presenting the original 2009 source as conclusively licensed under Apache 2.0.
