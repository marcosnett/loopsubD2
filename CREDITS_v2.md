# Credits

## Original Project

LoopsubD 2 is based on the original **Loop Subdivision** plugin for SketchUp created by:

**Nathan B (NB70)**  
Original project: Loop subdivision smoothing using the algorithm of Charles Loop.

The original source identifies Nathan B as the author and dates the source to June 2009.

The original project was distributed through Guitar-List and later appeared in the NB70 GitHub repository.

## LoopsubD 2

**Development:** Marcos Netto

LoopsubD 2 represents a substantial evolution of the original plugin, including:

- non-destructive Control Cage workflow;
- separate generated Subdivision Surface;
- subdivision levels 1–4;
- Crease support;
- Crease propagation;
- polygon triangulation;
- face-orientation correction;
- material handling;
- reliable Auto Update;
- SketchUp 2020 compatibility improvements;
- restructuring of the plugin architecture.

The LoopsubD 2 development is intentionally distinguished from the authorship of the original NB70 plugin.

## Licensing History Note

The original 2009 `loop_subdiv.rb` source examined during the development of LoopsubD 2 does not contain a formal license declaration.

A later version of the source committed to the NB70 GitHub repository in 2012 contains the source-code comment:

`# Apache 2.0 license`

The available repository history does not establish when or under what circumstances this notice was introduced.

For this reason, the historical licensing information is documented explicitly rather than presenting the original 2009 source as conclusively licensed under Apache 2.0.

This document is intended to record the available historical information accurately and to distinguish the original project from the subsequent LoopsubD 2 development.
